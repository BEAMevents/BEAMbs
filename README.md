# BEAMbs

Fills your extra displays with busy AV engineering screens — a streaming code terminal, network switch manager, routing matrix, fiber topology, audio meters, spectrum analyser, packet capture and sync/timecode — with a different setup on each display. By [BEAM Events](https://beamevents.com).

This repository only holds the **installers and updates** (Windows and Mac).

## Download
Get the latest version from **[Releases](https://github.com/BEAMevents/BEAMbs/releases/latest)**:

- **BEAMbs-Setup-x.y.z.exe** (Windows) installs BEAMbs and **updates itself automatically**. Use this one.
- **BEAMbs-Portable-x.y.z.exe** (Windows) runs without installing. It tells you when a newer version is out, but doesn't update itself.
- **BEAMbs-x.y.z-mac-arm64.dmg** (Mac, Apple Silicon): open it and drag BEAMbs to Applications. The first time, right-click it and choose Open. It updates itself like the Windows version.

The installers aren't code-signed yet, so Windows SmartScreen may warn on first launch: click **More info → Run anyway**.

## Updates
BEAMbs checks for updates in the background and shows **Update x.y.z ready** in its header. Click it, then **Install & restart**. Updates never install while a screen is live.
